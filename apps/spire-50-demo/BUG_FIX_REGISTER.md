# 종말의 탑 버그·수정사항 대장

최종 갱신: 2026-08-25

이 문서는 반복 버그를 막기 위한 단일 추적 문서다. 버그를 수정할 때는 반드시
`재현 조건 → 기대 동작 → 수정 위치 → 자동 테스트/수동 확인`을 함께 갱신한다.
상태가 `완료`여도 관련 테스트가 삭제되거나 검증 절차가 실패하면 다시 `회귀`로 연다.

## 수정 완료 체크리스트

1. 재현 조건과 기대 동작을 이 문서에 먼저 기록한다.
2. 가능하면 순수 함수 또는 도메인 상태 전이 테스트를 먼저 추가한다.
3. `pnpm --filter=spire-50-demo typecheck`를 실행한다.
4. `pnpm --filter=spire-50-demo test`를 실행한다.
5. `pnpm --filter=spire-50-demo build`를 실행한다.
6. 이동·전투·오디오·UI처럼 자동 테스트로 감각을 확인할 수 없는 항목은 실제 브라우저에서 재현 경로를 플레이한다.
7. 실패한 검증이나 남은 수동 확인은 `완료`로 표시하지 않는다.

## 5층 수동 회귀 시나리오

개발 서버에서 `?debugFloor=5&missionSeconds=120`로 진입한다.

1. 위쪽 대시 후 북쪽을 계속 바라보며 크기가 변하지 않는지 확인한다.
2. 보스가 먼저 문을 열고 HUD의 양 해안 이동이 `20/20`이 된 뒤 문을 닫으며 전술 선택을 표시하는지 확인한다.
3. 빨간 구조물 인식선이 맵의 벽·네 기둥·바위 외곽과 맞고, 닫힌 문 충돌선은 보이며 열린 문에서는 사라지는지 확인한다.
4. 가까운 병사 또는 양을 바라보고 G를 누르면 벽이나 다른 액터를 뚫지 않고 밀리는지 확인한다.
5. `2 · 맞서 싸운다`를 고르면 생존 병사 전원이 즉시 돌진하고 보스 처치 뒤 문이 열리는지 확인한다.
6. 정상 눈으로 열린 문에 접근하면 680px 경계 공격이 짧은 간격으로 반복되고 붉은 타격 지점 밖으로 피할 수 있는지 확인한다.
7. 은밀 탈출을 선택한 뒤 병사 번호 2명을 직접 선택·확정하고, 그 두 명만 희생된 후 수면 상태가 되는지 확인한다.
8. 수면 중 보스 앞에서 G를 누르면 울부짖으며 깨어나되 문은 열리지 않고, 실명이 이후 수면·기상을 거쳐도 유지되며 문 개폐 주기가 원래 일정대로 이어지는지 확인한다.
9. 실명 상태의 감지 190px·타격 48px 범위를 우회해 다음 주기에 열린 중앙 통로로 빠져나갈 수 있는지 확인한다.
10. 플레이어와 생존 병사 전원이 해안에 집결해도 5명 이하면 실패하고 6명 이상이면 휴식처 게이트 W로 완료되는지 확인한다.
11. 새 3×2 보스 포즈 시트, 체력바, 생존/집결/양 이동 수, 약점, 남은 시간이 1280×720에서 정상 표시되는지 확인한다.
12. N 키로 상세 정보 패널이 열리고 닫히며, 전술 결정·희생 선택 UI가 화면 하단에 표시되는지 확인한다.
13. 교전(타격 예고·추격·전면전) 중에는 상단 게이트 타이머가 `교전 중 정지`로 멈추고 문이 열리거나 닫히지 않는지, 깨어 있는 보스가 병사 2명을 잡아먹으면 문을 닫고(열려 있었다면) 잠드는지 확인한다.
