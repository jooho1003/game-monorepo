# 종말의 탑 버그·수정사항 대장

최종 갱신: 2026-08-25

이 문서는 반복 버그를 막기 위한 단일 추적 문서다. 버그를 수정할 때는 반드시
`재현 조건 → 기대 동작 → 수정 위치 → 자동 테스트/수동 확인`을 함께 갱신한다.
상태가 `완료`여도 관련 테스트가 삭제되거나 검증 절차가 실패하면 다시 `회귀`로 연다.

## 기존 회귀 방지 범위

현재 저장소에서 이미 자동화된 이전 수정사항도 같은 대장 범위로 관리한다.

| 범위 | 고정된 동작 | 자동 테스트 |
| --- | --- | --- |
| 휴식처 | 구조물 충돌과 전투/상점 게이트 위치가 플레이어 동선을 막지 않음 | `src/game/rest-layout.test.ts` |
| 일반 공략층 | 층별 난이도 상승, 생물군계/경계/장애물 배치가 유효함 | `src/game/battle-layout.test.ts` |
| 플레이어 방향 스프라이트 | 서쪽 미러링과 공격·스킬 텍스처 키가 섞이지 않음 | `src/game/player-animation.test.ts` |
| 5층 시간 규칙 | 5분 제한, 희생/공동 전투, 수면/문 개방 주기가 delta 크기에 무관함 | `src/domain/fifth-floor-mission.test.ts` |

## 수정 완료 체크리스트

1. 재현 조건과 기대 동작을 이 문서에 먼저 기록한다.
2. 가능하면 순수 함수 또는 도메인 상태 전이 테스트를 먼저 추가한다.
3. `pnpm --filter=spire-50-demo typecheck`를 실행한다.
4. `pnpm --filter=spire-50-demo test`를 실행한다.
5. `pnpm --filter=spire-50-demo build`를 실행한다.
6. 이동·전투·오디오·UI처럼 자동 테스트로 감각을 확인할 수 없는 항목은 실제 브라우저에서 재현 경로를 플레이한다.
7. 실패한 검증이나 남은 수동 확인은 `완료`로 표시하지 않는다.

## 5층 수동 회귀 시나리오

개발 서버에서 `?debugFloor=5&missionSeconds=120`로 진입한다.

1. 위쪽 대시 후 북쪽을 계속 바라보며 크기가 변하지 않는지 확인한다.
2. `2 · 맞서 싸우기`를 골라 병사가 장애물을 우회하고 보스를 공격하는지 확인한다.
3. `1 · 희생 설정` 경로에서는 보스가 손으로 병사를 잡고 피해 숫자와 체력 감소를 표시하는지 확인한다.
4. 수면 중 기본 공격 1회로 눈이 열리고, 스킬만으로는 실명되지 않으며, 눈을 조준한 두 번째 기본 공격에서 시야 부채꼴이 8초간 사라지는지 확인한다.
5. 보스가 바위까지 이동한 뒤 별도 바위 객체를 옮기는지 확인한다.
6. 양이 열린 출구를 통해 바닷가로 이동하고 막힐 때 우회하는지 확인한다.
7. 플레이어가 바닷가 게이트에서 `W`를 눌러 휴식처로 귀환하는지 확인한다.
8. 보스 체력바, 약점 상태, 남은 시간 문구가 1280×720에서 겹치지 않는지 확인한다.
