# 제50첨탑 (The Fiftieth Spire) 데모 로드맵

> **한 줄 목표**: 거대한 탑을 오르는 탑다운 액션 로그라이트의 첫 번째 층을, 타이틀부터 전투·보상·상점·귀환까지 한 사이클로 플레이할 수 있는 웹 데모로 만든다.
>
> **패키지/폴더명**: `apps/spire-50-demo`
> **기술 기반**: Phaser 3.90, Vite 6, TypeScript 5.7, pnpm/Turborepo
> **작성일**: 2026-08-20
> **상태**: 계획 수립 완료, 구현 대기

---

## Executive Summary

| 관점 | 내용 |
|---|---|
| **문제** | 현재 저장소에는 공용 코어와 클릭커 예시만 있고, 사용자가 요청한 타워 등반형 액션 게임의 화면 흐름·전투·보상 루프가 없다. |
| **해결** | `spire-50-demo`를 독립 Phaser 앱으로 추가하고, 데이터 중심 무기 정의와 씬 단위 화면 전환으로 1층 수직 슬라이스를 구현한다. |
| **기능/UX 효과** | 타이틀에서 시작해 캐릭터와 무기를 고르고, 휴식처 안내를 받은 뒤 전투·드롭 회수·상점 이용·포탈 귀환까지 끊김 없이 체험한다. |
| **핵심 가치** | 50층 확장 가능성을 유지하면서도 먼저 한 층의 손맛과 명확한 성장 보상에 집중한 검증 가능한 데모를 제공한다. |

## Context Anchor

| 키 | 값 |
|---|---|
| **WHY** | 참조 게임의 빠른 탑다운 전투와 전리품 회수 감각을 살린 독자적인 타워 등반 데모가 필요하다. |
| **WHO** | 키보드와 마우스로 플레이하는 데스크톱 웹 액션 게임 사용자. |
| **RISK** | 참조 이미지의 시각적 재현에 치우쳐 플레이 감각이 늦게 검증되거나, 타사 IP·자산을 그대로 복제할 수 있다. |
| **SUCCESS** | 신규 플레이어가 10분 이내에 1층의 전체 핵심 루프를 오류 없이 1회 완료하고, 조작·체력/마력·드롭·포탈 상태가 즉시 이해된다. |
| **SCOPE** | P0 기반/권리 확인 → P1 완전한 수직 슬라이스 → P2 무기 5종/연출 → P3 안정화·배포. |

## 1. 제품 방향과 범위

### 1.1 데모 판타지

- 플레이어는 50층짜리 거대 탑의 초보 도전자다.
- 데모는 **1층**만 실제 공략 가능하게 만들되, 타이틀의 층수 표시와 데이터 구조는 50층 확장을 전제로 한다.
- 첫 플레이의 감정 곡선은 `압도적인 탑 → 무기 선택 → 안전한 휴식처 → 첫 스킬 획득 → 전투 승리 → 전리품 회수 → 상점/귀환` 순서다.
- 참조작의 핵심 감각인 빠른 이동, 커서 지향 공격, 화면을 크게 쓰는 공격 이펙트, 짧은 전투 후 즉시 보상을 참고하되 명칭·캐릭터·맵·UI 장식·효과음은 독자적으로 만든다.

### 1.2 이번 데모에 포함

- 타이틀, 현재 도달 층수, 새 게임 버튼.
- 기본 캐릭터 1명과 무기 5종 선택 화면.
- Lv.1 초보자 상태와 선택한 무기 1개를 보존하는 런 상태.
- 탑 휴식처, 1층 공략 구역, 아이템 상점의 3개 맵.
- 탑 관리자와의 최초 진입 대화 및 첫 목표 안내.
- WASD 이동, 커서 지향 기본 공격, 숫자 `1` 스킬, `Z` 회수, 포탈 상호작용.
- 몬스터, 체력바, 피격/사망, 돈·아이템 드롭과 회수.
- 체력/마력 HUD, 빠른 데모용 자연 회복, 기본 사운드와 화면 피드백.
- 로컬 세션 안에서 최고 도달 층, 골드, 선택 무기 상태 유지.

### 1.3 이번 데모에서 제외

- 2~50층의 실제 스테이지와 보스 50종.
- 온라인 계정, 서버 저장, 멀티플레이, 결제.
- 완성형 장비 인벤토리, 제작, 퀘스트, 다중 캐릭터 해금.
- 무기별 완전한 스킬트리. 데모에서는 무기마다 첫 액티브 스킬 1개와 잠긴 후속 노드 미리보기만 제공한다.
- 모바일/게임패드 조작. 입력 추상화는 유지하되 데스크톱 키보드·마우스를 우선한다.

### 1.4 원작·참조물 사용 원칙

- `[세피리아]`는 전투 템포, 드롭 회수, HUD 정보 구조를 이해하는 **레퍼런스**로만 사용한다.
- `타이틀.jpg`의 실제 게임명·배경·폰트를 복제하지 않는다. 좌측 타이틀/세로 메뉴 구성, 손글씨 느낌, 깊이감 있는 환경 연출만 참고해 거대한 탑 중심의 독자 화면을 만든다.
- `캐릭1.jpg`는 사용자가 지정한 초기 캐릭터의 프로토타입 초상으로 사용하되, 배포 전 사용 권한을 확인한다. 실제 플레이용 탑다운 스프라이트와 애니메이션은 별도 제작한다.
- 제공 이미지의 제3자 로고, 원작 캐릭터, 맵 타일, UI를 게임 빌드에 그대로 포함하지 않는다.

### P1 — 핵심 수직 슬라이스 (최우선 플레이 가능 빌드)

목표: 임시 자산을 사용하더라도 시작부터 보상까지 한 사이클이 완주된다.

#### P1.1 타이틀과 선택

- [ ] 타워 전경 배경, 독자 타이틀 로고, 최고 도달 층/목표 50층 표시.
- [ ] `게임 시작` 버튼의 hover, 클릭, 키보드 포커스 상태.
- [ ] 캐릭터 카드 1개만 해금; 나머지 슬롯은 `봉인됨`으로 비활성 미리보기.
- [ ] 장검/단검/방패/활/지팡이 중 정확히 하나만 선택 가능.
- [ ] 선택 요약에 `Lv.1 초보자`, 기본 능력치, 공격 방식, 첫 스킬 표시.
- [ ] 선택 완료 전 출발 버튼 비활성, 완료 후 휴식처로 전환.

#### P1.2 휴식처와 대화

- [ ] 1층 휴식처에 플레이어, 탑 관리자, 공략 포탈, 상점 포탈 배치.
- [ ] 최초 진입 시 이동을 잠그고 관리자 대화를 자동 시작.
- [ ] 대화 내용: 탑의 목적, 50층 목표, 현재 1층, 조작법, 첫 임무.
- [ ] 첫 목표 한 줄을 HUD에 고정: `선택한 무기의 첫 스킬을 획득하라`.
- [ ] 대화 종료 시 선택 무기에 대응하는 첫 스킬 해금 및 숫자 `1` 슬롯 점등.

#### P1.3 이동과 전투

- [ ] WASD 8방향 이동, 대각선 속도 정규화, 벽/장애물 충돌.
- [ ] 마우스 커서 방향을 향하는 캐릭터와 공격 방향 표시.
- [ ] 우클릭 기본 공격: 무기별 공격 판정, 쿨다운, 모션/잔상, 타격 정지.
- [ ] 숫자 `1` 스킬: 마나 소모, 쿨다운, 커서 지향, 범위/투사체 판정.
- [ ] 최소 몬스터 2종: 근접 추적형과 원거리/돌진형 중 하나.
- [ ] 몬스터 하단 체력바, 피격 시 감소 애니메이션, 대미지 숫자, 사망 연출.
- [ ] 플레이어 체력/마력, 피격 무적 시간, 사망 시 휴식처 재시작.
- [ ] 데모 회복: 비전투 2초 후 HP 초당 8%, MP 초당 15%를 시작값으로 튜닝.

#### P1.4 보상·포탈·상점

- [ ] 몬스터 사망 시 골드와 아이템을 시드 기반 확률로 드롭.
- [ ] 드롭 근처에서 `Z`로 회수; 회수 범위, 흡수 애니메이션, 획득 토스트 표시.
- [ ] 공략 구역의 적 전멸 시 휴식처 귀환 포탈 활성화.
- [ ] 휴식처↔공략 구역, 휴식처↔상점의 양방향 포탈 구현.
- [ ] 포탈 위에서 `W`를 눌렀을 때만 이동. `W` 이동 입력과 겹치므로 250ms 유지 대신 `keydown` 1회로 발동하고 안내 프롬프트를 표시.
- [ ] 상점에서 골드로 회복 물약 또는 일회성 공격력 강화 1종 구매.
- [ ] 1층 클리어 결과 패널: 처치 수, 획득 골드, 아이템, 소요 시간.

**완료 게이트**

- 새로고침 후 타이틀부터 1층 클리어 결과까지 막힘 없이 진행된다.
- 캐릭터는 벽을 통과하지 않고, 공격은 쿨다운보다 빠르게 중복 발동하지 않는다.
- 적의 체력바가 피해량에 맞춰 줄고 0에서 사망/드롭이 정확히 한 번 발생한다.
- `Z` 회수와 두 종류 포탈로 3개 맵을 모두 방문할 수 있다.
- 체력/마력 회복과 스킬 마나 소모가 HUD에 즉시 반영된다.

### P2 — 무기 5종과 시각·청각 완성도

목표: 선택이 실제 플레이 스타일 차이로 이어지고, 임시 도형 없이 데모를 보여줄 수 있다.

| 무기 | 기본 공격 | 첫 스킬 | 전투 정체성 |
|---|---|---|---|
| 장검 | 넓은 전방 베기 | `반월참` — 큰 부채꼴 2연격 | 느리지만 넓은 범위 |
| 단검 | 짧고 빠른 연속 찌르기 | `그림자 돌진` — 커서 방향 관통 | 기동성과 단일 대상 폭딜 |
| 방패 | 방패 치기 | `수호 충격` — 전방 피해와 짧은 방어 | 생존과 밀쳐내기 |
| 활 | 직선 화살 | `세 갈래 사격` — 3방향 투사체 | 긴 사거리와 거리 유지 |
| 지팡이 | 작은 마력탄 | `별비` — 지정 방향/지점 범위 공격 | 마나 기반 광역 제어 |

- [ ] 무기별 공격 속도, 사거리, 피해량, 마나, 쿨다운 밸런스 1차 조정.
- [ ] 캐릭터 4방향 또는 8방향 idle/run/attack/hit 애니메이션.

## 4. 화면별 상세 요구사항

### 4.1 타이틀 화면

- 배경: 화면 하단에서 시작해 구름 너머로 끝이 보이지 않는 탑. 느린 구름과 작은 새/부유 석편으로 크기 대비를 만든다.
- 좌측: 독자적인 붓글씨 계열 로고 `제50첨탑`, 부제 `THE FIFTIETH SPIRE`.
- 로고 아래: `현재 최고 1F`와 `최종 목표 50F`.
- 메뉴: `게임 시작`을 주 CTA로 두고, 데모에서는 `설정`만 보조 제공. 저장 불러오기는 실제 저장 기능이 생길 때까지 노출하지 않는다.
- 버튼 피드백: 기본/hover/pressed/focus/disabled 상태를 모두 제공한다.

### 4.2 캐릭터·무기 선택

- 좌측 45%: `캐릭1.jpg` 기반 초상, 이름(임시: `에른`), `Lv.1 초보자`.
- 우측 상단: 무기 5종 탭. 한 번에 하나만 활성화하며 선택 무기를 캐릭터 실루엣/아이콘에 반영.
- 우측 중앙: 공격력/속도/범위/난이도를 텍스트와 막대로 비교.
- 우측 하단: 첫 스킬 설명과 출발 버튼.
- 접근성: 색상뿐 아니라 테두리, 아이콘, `선택됨` 라벨로 현재 선택을 전달.

### 4.3 게임 플레이 HUD

- 좌상단: 캐릭터 초상, Lv.1, HP(빨강), MP(청록), 현재 골드.
- 상단 중앙: `탑 1층 · 휴식처/공략 구역/상점`과 첫 목표 한 줄.
- 우상단: 간단한 미니맵 또는 현재 구역/포탈 방향 표시. P1에서는 텍스트 방향표도 허용.
- 우하단: 우클릭 기본 공격, `1` 스킬 슬롯, 쿨다운 원형 마스크, 마나 비용.
- 캐릭터/몬스터 주변: 적 체력바는 각 몬스터 하단, 대미지 숫자는 피격 지점에서 짧게 상승 후 소멸.
- 중앙 하단: `Z 회수`, `W 포탈 이동`, 관리자 대화 등 상황별 프롬프트.

### 4.4 대화 UI

- 화면 하단 약 30% 높이의 반투명 어두운 패널.
- 관리자와 플레이어 초상을 대사 화자에 따라 강조하고, 이름표와 본문을 분리.
- 클릭/`Space`로 다음 대사, 길게 누르지 않아도 한 번에 한 단계만 진행.
- 대화 중 공격과 이동은 잠그되 설정 메뉴는 열 수 있다.
- 마지막 대사 종료 시 목표 토스트와 스킬 해금 연출이 연속으로 나온다.

### 6.2 상태 흐름

```text
Boot
  → Title
    → Select(character=default, weapon=one of five)
      → Rest(firstVisit dialogue → unlock skill)
        ↔ Battle(clear enemies → loot → activate return portal)
        ↔ Shop(buy one demo item)
```

### 6.3 핵심 데이터 모델

- `RunState`: 캐릭터 ID, 무기 ID, 레벨, HP/MP, 골드, 인벤토리, 현재/최고 층, 목표, 첫 방문 플래그.
- `WeaponDefinition`: 기본 공격 수치/판정/애니메이션 키, 첫 스킬 ID, 아이콘, 설명.
- `SkillDefinition`: 피해 배율, 마나, 쿨다운, 범위 형태, 투사체/근접 여부, 이펙트 키.
- `EnemyDefinition`: 최대 HP, 이동/공격 방식, 피해량, 드롭 테이블, 체력바 오프셋.
- `PortalDefinition`: 출발 구역, 도착 구역, 활성 조건, 상호작용 키.
- `DialogueSequence`: 화자, 초상, 본문, 종료 후 이벤트.

### 6.4 구현 원칙

- Phaser 오브젝트 수명은 씬이 관리하고, 전투 수치 계산은 가능한 한 순수 함수로 둔다.
- 씬 사이 전역 이벤트 리스너는 종료 시 반드시 해제해 중복 공격/대화 진행을 막는다.
- 무기별 분기문을 퍼뜨리지 않고 `WeaponDefinition`과 전략 함수로 판정을 교체한다.
- 밸런스 수치는 한 파일에서 조정하고 코드에 매직 넘버를 넣지 않는다.
- 게임 랜덤은 `Math.random()` 대신 `@game/core`의 `createRng(seed)`를 사용한다.
- 저장은 P1에서 `localStorage` 한 슬롯으로 제한하고 버전 필드를 둔다.

## 10. 커밋·검증 운영 규칙

- 한 커밋은 위 체크포인트 하나의 실행 가능한 상태를 담는다.
- 커밋 전 최소 `pnpm typecheck --filter=spire-50-demo`와 해당 테스트를 실행한다.
- P1 완료 이후에는 루트 `pnpm build`, `pnpm test`, `pnpm typecheck`를 모두 실행한다.
- 사용자가 만든 기존 변경은 섞지 않고 `apps/spire-50-demo` 및 필요한 공용 코드만 선택적으로 스테이징한다.
- 자산 추가 커밋에는 `assets/README.md`의 출처/권리 상태 갱신을 포함한다.
- 임시 자산은 파일명 또는 장부에 `prototype-only`로 표시하고 배포 게이트에서 차단한다.

|---|---|---|
| 가칭 | `제50첨탑 / The Fiftieth Spire` | 50층 목표를 즉시 전달하고 참조작 명칭을 사용하지 않음. |

| 아트 방향 | 고대 탑 + 구름 + 청록 마력의 2D 픽셀/페인터리 혼합 | 타이틀의 깊이감과 전투 캡처의 가독성을 함께 살림. |
