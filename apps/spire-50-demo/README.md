# 종말의 탑 데모

층마다 만나는 방랑자가 아군일지 적군일지 달라지는 웹 기반 탑다운 액션
로그라이크의 플레이 가능한 P0 뼈대입니다.

현재 빌드는 제공된 타이틀 배경과 Phaser 도형·CSS로 다음 흐름을 검증합니다.

```text
타이틀 → 캐릭터/무기 선택 → 휴식처 대화
       → 1층 전투·방랑자 조우·드롭 회수
       → 휴식처 → 2~4층 전투
       → 5층 외눈박이 동굴 탈출전 → 휴식처 → 아이템 상점
```

## 실행

저장소 루트에서:

```bash
pnpm install
pnpm --filter=spire-50-demo dev
```

브라우저에서 `http://localhost:5174`를 엽니다.

## 검증

```bash
pnpm --filter=spire-50-demo typecheck
pnpm --filter=spire-50-demo test
pnpm --filter=spire-50-demo build
```

## 조작

| 입력                   | 동작                |
| ---------------------- | ------------------- |
| `WASD`                 | 이동 (같은 방향 2회 입력 시 대시) |
| 마우스 우클릭          | 커서 방향 기본 공격 |
| 숫자 `1`               | 커서 방향 범위 스킬 |
| `Z`                    | 가까운 골드 회수    |
| 포탈 위 `W`            | 구역 이동           |
| `Space` 또는 대화 버튼 | 대화 진행           |
| 5층 화면 선택 버튼     | 병사 희생/공동 전투 선택 |
| `Esc`                  | 타이틀로 돌아가기   |

## P0에서 확인할 것

- 타이틀과 무기 선택이 React UI로 동작합니다.
- 타이틀에서 새 게임을 시작하거나 저장된 런을 불러올 수 있습니다.
- 게임 월드와 입력은 Phaser가 담당합니다.
- 런 상태는 순수 TypeScript 전이 함수와 Zustand 단일 스토어를 거칩니다.
- 첫 진입 대화를 끝내면 스킬이 해금됩니다.
- 전투장의 방랑자는 런 시드에 따라 아군 또는 적군이 됩니다.
- 적을 쓰러뜨리고 `Z`로 골드를 주운 뒤 휴식처로 귀환할 수 있습니다.
- 상점에서 골드를 사용해 체력을 회복할 수 있습니다.
- 5층은 5분 안에 외눈박이의 시야를 제어하고, 보스가 옮긴 바위문을 지나 바닷가 휴식처 게이트로 탈출하는 보스전입니다.
- 보스와 출구를 막는 바위는 별도 객체입니다. 보스가 주기적으로 바위까지 이동해 출구를 열고 다시 막습니다.
- 5층에는 양 20마리와 병사 15명이 있으며, 양은 동굴과 바닷가를 왕복하고 병사는 공동 전투 선택 시 보스를 공격합니다.
- 잠든 보스를 기본 공격으로 한 번 깨운 뒤 노출된 눈을 다시 기본 공격하면 8초 동안 시야를 막을 수 있습니다. 스킬은 보스 체력을 깎지만 이 약점 순서를 대신하지 않습니다.
- 외눈박이가 병사를 잡을 때 손으로 끌어올리는 피해 연출과 병사 체력 감소가 표시됩니다.
- 5층 미션 실패 시 실패 화면을 표시하고 현재 5층을 유지한 채 휴식처로 자동 귀환합니다.
- 진행 상태는 버전이 붙은 `localStorage` 단일 슬롯에 저장됩니다.

## 현재 제한

- P0 전투 판정과 AI 일부는 Phaser 프로토타입 계층에 있습니다.
- 현재 스프라이트와 음원은 프로토타입 품질이며, 자산별 출처와 배포 상태는 `public/assets/README.md`에 기록합니다.
- 1~5층 진행과 첫 보스 탈출전이 가능하며 6~50층의 고유 이벤트는 후속 단계입니다.
- 무기 선택은 저장/UI에 연결되어 있지만 고유 판정 차이는 후속 단계입니다.

상세 우선순위는 [ROADMAP.md](./ROADMAP.md)를 참고하세요.
